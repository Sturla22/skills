# Work Plan

## Problem statement

Determine whether GitHub Copilot supports a repo-level default custom agent, and if so whether `product-owner` can be made the default.

## Approach

1. Review repo-local evidence showing how custom agents are generated and consumed.
2. Review official Copilot CLI documentation for agent selection and config.
3. Search for authoritative GitHub docs covering custom agents and any default-selection mechanism.
4. Record findings, gaps, and the research boundary.
